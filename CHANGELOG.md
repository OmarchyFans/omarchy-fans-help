# Changelog

The help window reads the newest sections of this file to tell you what changed
when an update is available. Keep one short line per bullet.

## 0.3.1

- The window tells you when a new version is out, shows what changed, and updates in one click
- It also notices when the window and its helpers are out of step, and finishes the update
- install.sh offers to download the local model (Qwen3.8-4B-Distill, 2.6 GB) and start it

## 0.3.0

- Build it: turn a missing feature into an Omarchy plugin or an omarchy.fans cloud web app
- Hand the build to Rix, Hermes, Claude Code, Codex, Grok, Gemini or OpenCode
- A "Do it." scene plays before the hand-off
